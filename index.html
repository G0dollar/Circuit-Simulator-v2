Electricity Circuit Simulator

A real-time grid-based electrical simulator with nodal analysis, visual measurement tools, and smooth interactive controls.

Run the Desktop Application

Download the compiled executable JAR file and run it directly on Windows, macOS, or Linux.

Download CircuitSimulator.jar

Requires Java JDK (17+) installed on your system.

Having trouble? View instructions on the GitHub Repository.

⚡ Nodal Solver

Calculates currents, voltages, and voltage drops using Modified Nodal Analysis (MNA) and Gaussian elimination.

🔄 Auto-Routing

Wires automatically detect neighbors and snap into place, adapting straight, corner, T-junction, and cross alignments.

⏮️ Undo / Redo

Fully tracked actions via the Command Pattern history stack. Revert or reapply actions using Ctrl+Z and Ctrl+Y.

🔍 Pan & Zoom

Navigate a massive 50x50 layout using keyboard scrolling (Arrow/WASD) and scaling (+/- keys).

Keyboard and Mouse Controls

Action Control Description
Place Component Left-Click Places the selected component tool onto the grid.
Rotate Component Right-Click or R Rotates hovered component CW.
Delete Component Delete or Backspace Erases the hovered component on the grid.
Toggle Switch / Cycle C Toggles Switch ON/OFF or cycles wire shapes manually.
Change Values Double-Click Opens parameter dialogue (voltage, resistance).
Undo / Redo Ctrl + Z / Ctrl + Y Reverts or reapplies the previous edit command.
Canvas Pan Arrow Keys / WASD Scrolls viewport across the 50x50 grid.
Canvas Zoom + / - Zoom in and out centering on the cursor.
