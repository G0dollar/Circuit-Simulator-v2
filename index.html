Electricity Circuit Simulator

A real-time grid-based electrical simulator with nodal analysis, transient and AC behavior, live measurement and graphing tools, and a custom-built interface.

⚡ Nodal Solver

Calculates currents, voltages, and voltage drops using Modified Nodal Analysis (MNA) and Gaussian elimination, across multiple independent circuits on the same grid.

🌀 Transient & AC Behavior

Capacitors and inductors charge and discharge over time, diodes and LEDs converge to the correct bias state, and AC motors generate a live time-varying sine voltage.

🛡️ Solver Diagnostics

Floating or singular nodes are automatically detected and flagged with a visible warning, instead of silently reporting a misleading zero.

🔄 Auto-Routing

Wires automatically detect neighbors and snap into place, adapting straight, corner, T-junction, and cross alignments, with a live current heat-map tint.

📈 Graphing & Oscilloscope

Plot any component's live voltage or current on a rolling graph, or open a multi-channel oscilloscope to monitor several sources at once.

💾 Save & Load Circuits

Save a full circuit layout — components, values, orientation, and wiring — to a file, and reopen it later.

⏮️ Undo / Redo

Fully tracked actions via a Command Pattern history stack. Revert or reapply edits using Ctrl+Z and Ctrl+Y.

🔍 Pan & Zoom

Navigate a massive 50x50 layout using keyboard scrolling, middle-drag panning, and scroll-wheel or keyboard zoom.

🎨 Custom Dark Interface

A dedicated dark design system spans the canvas, property editor, sidebar, and graph/oscilloscope panels — not the default Swing look.

Keyboard and Mouse Controls

Action Control Description
Place Component Left-Click Places the selected component tool onto the grid.
Rotate Component Right-Click or R Rotates the hovered component clockwise.
Delete Component Delete / Backspace Erases the hovered component on the grid.
Toggle Switch / Cycle Wire C Toggles a Switch ON/OFF or cycles a wire's geometry.
Configure Parameters Double-Click Opens the property editor, showing a live readout alongside editable values.
Open Graph Alt+Click or G Opens a real-time voltage/current graph for the hovered component.
Toggle Oscilloscope Ctrl+Shift+O Opens the multi-channel oscilloscope.
Undo / Redo Ctrl+Z / Ctrl+Y Reverts or reapplies the previous edit.
New / Open / Save / Save As Ctrl+N Ctrl+O Ctrl+S Ctrl+Shift+S Manage circuit files.
Canvas Pan Arrow Keys / WASD / Middle-Drag Scrolls the viewport across the 50x50 grid.
Canvas Zoom Scroll or + / - Zooms in and out, centering on the cursor.
Reset View Home Resets zoom and pan.
